# Community code of conduct

We want collaboration here to be technically rigorous, respectful, and safe for people with different backgrounds and levels of experience.

## Expected conduct

- Discuss evidence and design tradeoffs without attacking people.
- Be clear about assumptions, uncertainty, authorship, and AI assistance.
- Respect privacy, consent, intellectual property, and security boundaries.
- Give actionable review feedback and allow maintainers reasonable time to respond.
- Stop testing or publishing details when doing so could expose a person, credential, or vulnerable system.

Harassment, threats, discriminatory conduct, doxxing, deliberate deception, spam, and unsafe disclosure are not acceptable.

## Enforcement

For ordinary conduct concerns, contact the maintainer privately through the GitHub profile linked from the repository owner. For security-sensitive reports, use the private vulnerability-reporting path described in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content, close interactions, or restrict participation when needed to protect the project and its community.

This policy applies in repository discussions and in public spaces when someone represents this project.
