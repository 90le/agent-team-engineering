# 项目定位与边界

## 愿景

让一个已有或新建的软件项目能够在不依赖历史聊天、单一AI厂商或单台设备的情况下，接入一个有权限边界、质量门禁、审计和恢复能力的多智能体软件团队。

## 第一阶段交付

- 开放 JSON 契约和版本化工作流。
- `software-delivery` 参考团队包。
- 无副作用模拟控制器与安全负例测试。
- Codex、Claude、OpenClaw、GitHub 和通用 AI 的薄适配器。
- 现有仓库只读分析与接入提案生成器。
- Git 空目录冷启动和迁移验收。

## 明确不做

- 不把语言模型输出当成批准。
- 不提供生产 root Shell、Docker Socket 或秘密读取能力。
- 不承诺所有反馈都应开发或自动上线。
- 不在第一阶段连接真实生产环境。
- 不把聊天、向量索引或运行数据库当成唯一权威。
