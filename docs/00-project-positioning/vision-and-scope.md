# 项目定位与边界

## 愿景

让一个已有或新建的软件项目能够在不依赖历史聊天、单一AI厂商或单台设备的情况下，接入一个有权限边界、质量门禁、审计和恢复能力的多智能体软件团队。

## 已完成：v0.1参考内核

- 开放 JSON 契约和版本化工作流。
- `software-delivery` 参考团队包。
- 无副作用模拟控制器与安全负例测试。
- Codex、Claude、OpenClaw、GitHub 和通用 AI 的薄适配器。
- 现有仓库只读分析与接入提案生成器。
- Git 空目录冷启动和迁移验收。

## 当前阶段：Agent Team Factory

参考内核证明了边界，但不能自动成为某个用户的长期团队。Factory阶段增加：

- 声明式团队实例、严格Schema、版本锁和契约摘要。
- 不覆盖已有路径的原子实例生成器与漂移检测。
- 已完成v0.3持久工作流、租约、幂等、副作用出站箱、暂停、哈希链审计和故障恢复。
- 已完成v0.4供应商中立适配器SDK、事件授权、绑定批准、签名Webhook边界、隔离Runner接口与契约测试。
- 已完成v0.5可验证发布安装、结构化Doctor、摘要绑定实例升级、外部恢复包、崩溃恢复和可逆回滚。
- 已完成目标仓库不落盘的项目发现、摘要绑定接入包和proposal-only候选配置。
- 能由不同AI和新设备执行的安装、诊断、冷启动、升级与交接协议。
- 已完成v0.6 Team Blueprint编译器、OpenClaw/Codex/Claude/Generic AI原生资产、Codex/Claude CLI路由和可重启的反馈到经审核Draft PR参考运行时。

Factory仓库、实例仓库和目标业务仓库保持分离。首个实际团队是Factory的采用项目，不是通用源码的一部分。

“已完成”指通用创建、验证和参考执行闭环已经由自动验收证明；不表示采用者的OpenClaw频道、模型账号、GitHub权限、生产Runner或业务项目已自动接入。长期无人值守运行属于基于Factory接口建设的采用工程。

## 明确不做

- 不把语言模型输出当成批准。
- 不提供生产 root Shell、Docker Socket 或秘密读取能力。
- 不承诺所有反馈都应开发或自动上线。
- 不在Factory建设项目中绑定任何采用者的真实生产环境。
- 不把聊天、向量索引或运行数据库当成唯一权威。
