# 现有项目接入协议

## 接入阶段

1. 只读发现语言、框架、构建、测试、CI、文档和现有AI入口。
2. 在目标仓库外生成接入报告和 `.agent-team` 提案。
3. 由项目所有者补充使命、非目标、风险偏好、生产边界和验收方式。
4. 在 `proposal/adopt-agent-team` 分支加入入口、策略和门禁。
5. 执行模拟流程、安全负例和项目原有测试。
6. 先启用 A1/A2；积累证据后再讨论更高自治等级。

## 不得自动推断

- 生产部署命令和凭据。
- 数据库是否允许回滚。
- 谁拥有产品和安全批准权。
- 现有测试是否足够作为发布门禁。
- 仓库写权限是否等同于生产授权。

使用方法见仓库根目录 [README](../../README.md)。生成器保证输出位于目标仓库外，避免未授权覆盖。
