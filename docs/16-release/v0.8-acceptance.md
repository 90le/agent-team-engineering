
真实 GitHub SCM 证据仓库只包含无业务数据的测试 Issue、提案分支、一个文件提交和未合并 Draft PR；它不是公开产品实例。若该证据尚未完成，`acceptance/v08-native-conformance.json` 会保持 `AUTHORIZED_EVIDENCE_PENDING`，带 `--require-external-evidence` 的发布审计和标签工作流都会失败，不能创建 Release。审计还要求第一次运行四个对象均为新建、第二次运行四个对象均为零新增且引用完全相同；证据绑定的框架提交之后只能增加验收报告、门禁状态和发布索引，不能再修改实现代码。
